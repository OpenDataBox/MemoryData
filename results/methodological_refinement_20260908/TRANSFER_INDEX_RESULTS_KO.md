메모리는 원문으로 구성하고, 필요한 source 선택에는 원문 기반 probe를 사용했다. 아래 점수는 기존 개발 70문항 평가이며 새 일반화 성능이 아니다.

350개 예측을 재채점하고 소스 hash·문항 분리·읽기 상한·대화별 저장 상한을 검증했다. 4개 recipe가 만든 서로 다른 텍스트 메모리 모음은 1개다. 텍스트는 동일하지만 학습한 dense index는 4개로 서로 다르다. 벡터 배열 바이트도 별도로 검증했다.
동일 저장 상한을 적용했지만 실제 사용량은 다를 수 있다. 검색 키와 원문 payload를 모두 비용에 포함한다. 같은 모델의 의미 검증은 사실성 증명이 아니다.
원문·검색 텍스트·출처·모델 가중치는 고정하고 저장된 문서 벡터만 학습했다. 텍스트와 벡터 배열의 저장량은 모든 대조군에서 같다. 학습 source 질문의 개선이 새 질문의 개선을 보장하지 않는다.
