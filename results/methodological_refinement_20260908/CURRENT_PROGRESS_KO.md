# 현재 refinement 상태

개발 70문항의 현재 최고는 **s_parent_single_2000, F1 59.27437**다. 직전 r40의 58.62030 대비 **+0.65407점**, 지속 refinement 시작점 52.79428 대비 **+6.48010점**이다. 새 일반화 점수는 아니다.

별도로 고정한 방법의 [새 100문항 checkpoint](PORTABLE_AUDIT_RESULTS_KO.md)를 완료·검증했다. **초기 seed 53.36868 → r40 54.39625 → parent 54.84030 F1**이다. parent는 초기 대비 **+1.47162점**, 질문 빈도로 가중한 저장량은 **약 15.07% 감소**했다. r40 대비 추가 이득은 **+0.44404점**, 대화별 bootstrap 95% 구간은 **[-1.00126, +2.27782]점**으로 0을 포함한다. 기존 pilot에 등장했던 세 대화의 새 질문이며 미사용 대화의 일반화 결과는 아니다.

기존 최고 메모리의 원문 출처를 덮는 unit에 source-generated 질문 단서를 붙이고, 대화별 추가 2000토큰 상한에서 선택했다. 평균 저장량은 57,177 → 59,113토큰, 읽기량은 2015토큰이다. 새로운 날짜·키워드 규칙은 추가하지 않았고 기존 backend의 규칙은 그대로 고정했다. 더 큰 저장 예산이나 공동·검증 후보가 항상 좋지는 않았다.

- [최고 backend에서의 대조 결과](PARENT_RESULTS_KO.md): 14개 대조군과 기준점의 1050개 예측 재채점, 소스 hash와 읽기·저장 상한 검증.
- [원문 baseline에서의 대조 결과](BUDGETED_RESULTS_KO.md): 45.967 → 47.888, 11개 recipe 중 서로 다른 메모리는 6개. 840개 예측 검증.
- [전체 source-fit 진단](EVIDENCE_FIT_KO.md): 278개 probe, 13,792개 확률 추적 검증. NLL만으로 고른 최소 증거는 작은 pilot의 개선을 유지하지 못했다.
- [방법론과 데이터 경계](PROTOCOL_KO.md): source-fit 기반 구성, 동일 read budget, source-only 선택과 이후 dev 평가, 기존 연구와의 겹침.

실제 검색 경로에서 source-only 재귀 선택을 두 방식으로 완료했다. [기존 질문 Q0 기준](SOURCE_RECURSION_KO.md)은 source 보존 80→94/97이었지만 개발 F1은 59.13으로 최고를 갱신하지 못했다. 1649개 source 예측과 140개 개발 예측을 검증했다.

[다른 표현으로 선택한 실험](CROSSVIEW_SOURCE_KO.md)은 동일 75개 사실에서 Fit A 60→63, 선택 후 Audit B 63→61, [개발 F1 56.66](CROSSVIEW_RESULTS_KO.md)이었다. 1275개 source 예측, 생성 질문의 원문 출처와 배정, 12개 후보의 선택 및 상한, 140개 개발 예측을 검증했다. A와 B 전체 문구 교집합은 0개다. B는 후보 성능을 보기 전에 원문 기반 품질 교정에 사용했으며, 메모리 성능은 선택 고정 후에만 평가했다. 이제 B 결과는 노출되었으므로 새로운 비공개 audit로 재사용하지 않는다.

증거 중복 통합 9개 대조군은 완료했고 모두 최고를 넘지 못했다. [개발 예측 700개](IDENTITY_RESULTS_KO.md)와 [source 예측 1,720개 및 메모리 재구성](IDENTITY_SOURCE_KO.md)을 검증했다. 모든 서로 다른 증거를 보존했어도 검색 키의 변경은 기존 source 답 일부를 잃게 했다. source 선택은 기존 최고를 유지했다. 단순 통합 자체의 학술적 신규성을 주장하지 않는다.

[고정한 parent_single 정책의 새 100문항 checkpoint](PORTABLE_AUDIT_PROTOCOL_KO.md)는 정상 종료했다. 300개 새 질문 예측과 70개 기준 재현 예측, 원문 기반 probe 136개와 확률 추적 6,317개, 생성 창 255개, 출처·메모리 hash·문항 분리·평가 전 고정·상한을 검증했다. 해당 대화에서 별도로 나눈 source session audit 42개는 사용하지 않았다. 이 100문항 결과는 후속 튜닝에 사용하지 않는다.

[사건 구분 키 실험](CONTRASTIVE_SOURCE_KO.md)은 완료·검증했다. 같은 원문 쌍의 literal 대조군보다 높았으나 최선 F1 58.64로 기존 최고를 넘지 못했다. 448개 키 생성의 원문 출처, 750개 source 예측, 350개 개발 문맥·예측, 실제 토큰 수, 4개 전체 메모리 재구성 및 선택 시각을 검증했다. 같은 모델의 SUPPORTED 437건은 사실성 인증이 아니다. [선등록 hash와 시각](CROSS_EXPERIMENT_SEPARATION.json)은 별도 audit100 이전 고정을 확인한다.

[저장 문서 벡터 직접 학습](INDEX_SOURCE_KO.md)도 완료·검증했다. 반경 0.03/0.1/0.3의 [개발 F1](INDEX_RESULTS_KO.md)은 각각 56.77/57.35/56.67이며 기존 최고를 유지한다. source Q0의 답 보존 순증가는 +2/+4/+4였지만 다른 표현 A는 -4/0/0이었다. 세 후보의 텍스트 및 벡터 배열 저장량은 같다. 벡터 21개의 200단계 학습을 오차 0으로 재현했고, 저장된 질문/문서 벡터로 880개 실제 검색 문맥·출처·토큰·F1을 검증했다. 원래 평가기의 70개 기준 문맥·예측도 전부 동일했다. 큰 반경에서는 정답 출처 회수율이 82.57%에서 85.40%로 올라도 F1은 2.60점 하락했다. [대화 간 전이와 거리 보존 정렬](TRANSFER_INDEX_SOURCE_KO.md)은 완료·검증했다. 네 조건의 개발 F1은 55.12/56.64/56.74/53.29로 최고를 넘지 못했다. 28개 정렬 결과를 오차 0으로 재현하고, 1,100개 실제 검색 문맥·출처·토큰·F1, 대상 대화의 학습 제외, 문서 간 내적 보존과 선택 시각을 검증했다. source 선택은 Q0/A 순증가 +1/+3을 보인 within 0.3이었지만 개발 F1은 56.74였다. 두 표현의 source 개선도 개발 성능을 보장하지 않았다.

[원문 인용과 삭제 검사로 본문을 구성한 실험](PAYLOAD_SOURCE_KO.md)은 완료·검증했다.
