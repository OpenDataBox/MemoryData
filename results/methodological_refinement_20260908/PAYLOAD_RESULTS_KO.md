메모리는 원문으로 구성하고, 필요한 source 선택에는 원문 기반 probe를 사용했다. 아래 점수는 기존 개발 70문항 평가이며 새 일반화 성능이 아니다.

350개 예측을 재채점하고 소스 hash·문항 분리·읽기 상한·대화별 저장 상한을 검증했다. 4개 recipe가 만든 서로 다른 텍스트 메모리 모음은 4개다. 동일 메모리를 독립 반복 실험으로 세지 않는다.
동일 저장 상한을 적용했지만 실제 사용량은 다를 수 있다. 검색 키와 원문 payload를 모두 비용에 포함한다. 같은 모델의 의미 검증은 사실성 증명이 아니다.
검색 키·순서와 모델을 고정하고 읽기 payload만 구성했다. 원문 focus를 보존하며 기존 unit보다 길어지면 원래 payload로 되돌린다. 검색 순위는 같지만 payload 길이에 따라 읽기에 포함되는 unit은 달라질 수 있다. 변경된 본문과 고정 검색 키를 모두 저장하므로 기존 최고 대비 저장량이 늘 수 있고, 상한은 기존의 2배다.
