# 대화 간 전이와 메모리 거리 보존

직접 문서 벡터 학습은 source Q0의 답 보존을 늘려도 질문 표현 A와 개발 F1 개선으로 이어지지 않았다. 다음 실험은 각 문서가 독립적으로 이동하는 자유도를 제거하고, 대화의 모든 메모리 벡터에 하나의 직교 변환을 적용한다. 메모리끼리의 내적·거리는 보존하면서 고정 질문 encoder와의 정렬만 바뀐다.

각 source Q0 질문과 해당 답의 출처 ID를 공유하는 메모리 벡터의 정규화된 평균을 짝짓는다. 이 쌍의 정렬 손실에서 얻는 반대칭 방향을 Cayley 변환으로 바꾸고, 학습 쌍이 만드는 부분 공간 바깥은 항등 변환으로 둔다. 변환의 최대 이동 반경을 0.1 또는 0.3으로 고정한다. 문서 벡터, 원문, 모델 가중치, sparse key, RRF, packing, 읽기 2048토큰 상한의 비용 조건은 앞선 실험과 같다. 반복 gradient 학습은 하지 않는다.

반경마다 두 조건을 비교한다.

- within: 해당 대화의 source-fit Q0만으로 정렬을 구한다.
- transfer: 해당 대화의 source 질문은 전부 제외하고 다른 여섯 개발 대화의 Q0만으로 정렬을 구한다.

모든 정렬을 고정한 뒤 동일 75개 사실의 Q0/A 답 보존으로 후보를 선택하고, 선택 hash를 고정한 뒤 개발 70문항을 평가한다. 두 표현 모두 순증가가 양수여야 source 선택이 가능하다. 개발 F1 최고를 따로 보관한다. 새 audit100과 노출된 표현 B는 사용하지 않는다.

전이 조건은 현재 대화의 source 질문을 학습에 쓰지 않는다는 뜻이다. 이미 개발에서 여러 번 사용한 대화 자체가 새로워지는 것은 아니다. 또한 다른 대화에서 학습하더라도 같은 데이터셋·생성 모델의 공통 편향이 남을 수 있다.

대상 대화의 Q0/A는 변환을 맞추는 데 쓰이지 않지만, 모든 변환을 고정한 뒤 공통 후보 선택에는 포함된다. 따라서 학습 단계의 대화 제외를 최종 선택까지 완전히 독립인 평가로 해석하지 않는다.

직교 정렬, Cayley 변환, leave-one-conversation-out 학습 자체의 신규성을 주장하지 않는다. 여기서 검증할 가설은 질문별 수정 자유도를 줄이고 원래 메모리 간 관계를 보존할 때, 원문 감독 신호가 해당 질문 표현을 넘어 실제 메모리 답변에 전이되는지다. 구성과 선택 코드는 실행 전에 고정했다.
