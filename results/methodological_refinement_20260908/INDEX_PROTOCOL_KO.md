# 저장된 메모리 벡터의 원문 감독 학습

원문·검색 텍스트·출처·읽기 상한 2048토큰 및 기존 Qwen reader를 고정한다. 문서와 질문 encoder의 가중치도 그대로다. 메모리 구성 결과로 저장하는 문서 벡터만 학습한다. 단순한 새 날짜/키워드 규칙을 추가하지 않는다.

개발 대화 원문에서 생성한 Q0 97개 질문과 답 출처 ID로 multi-positive retrieval loss를 구성한다. 해당 출처를 하나 이상 공유하는 메모리 unit의 확률 질량을 늘린다. 이는 약한 감독 신호이며 답을 충분히 지지한다는 의미는 아니다. 벡터를 원래 임베딩 주위 구면 영역 안으로 투영하며 Adam 200단계, 학습률 0.01, 온도 0.05를 고정했다. 반경 0.03/0.1/0.3 세 개만 비교한다.

모든 벡터 학습을 마치고 hash를 고정한 뒤 동일 75개 사실의 Q0/A 표현으로 실제 BM25+dense RRF, packing, reader까지 검사한다. A는 gradient 학습에 사용하지 않는다. 두 표현 모두 보존 답 순증가가 양수인 후보 중 작은 쪽 증가량, 합계, 작은 반경으로 고른다. 해당 선택은 모든 새 개발 점수를 보기 전에 고정한다. 개발 점수 최고는 별도의 탐색 결과로 기록한다.

세 후보의 텍스트 저장량 및 벡터 배열 바이트는 같다. 새 evaluator의 유일한 검색 입력 차이는 공급받은 문서 벡터이며, 변형 전 벡터에서 기존 70문항의 검색 문맥·예측·출처·토큰·F1 완전 일치가 필수 gate다. 실행에서 이 gate가 통과했다.

이미 소비한 별도 audit100, 노출된 질문 표현 B, source session audit86은 학습/선택에 넣지 않는다. QA를 포함한 공개 파일은 원문 파싱 과정에서 로드되지만, 새 메모리 최적화 함수에는 원문 유래 Q0만 전달한다. 벤치마크 질문·정답으로 gradient를 만들지 않는다.

신규성은 아직 입증하지 않았다. 저장 문서 벡터를 작게 수정하여 검색 순위를 교정하는 관련 연구로 [Embedding Surgery](https://arxiv.org/abs/2609.05110)가 있으며, 문서 임베딩 이동을 억제하는 관련 설계로 [DEPT](https://arxiv.org/abs/2608.17632)가 있다. 두 논문의 공식 초록을 확인했다. 따라서 직접 벡터 학습이나 이동 제약 자체를 새로운 기여로 주장하지 않는다. 현재 비교는 원문에서 얻은 감독 신호가 고정된 메모리 읽기 경로의 실제 답 보존으로 이어지는지 검증하는 실험이다.
