# 기존 본문을 보존하는 사실 검색 단서

본문 교체 실험에서는 원문만 읽은 대조군도 F1 52.73으로 기존 59.27보다 낮았다. 이번에는 기존 메모리 전체를 그대로 유지하고, 검증한 원문 사실을 추가 검색 키로 사용한다. 새 키로 검색되었을 때 읽는 본문은 기존 unit의 정확한 복사본이다.

완료된 원문 compiler의 SUPPORTED 문장을 후보로 삼되, 인용한 모든 source ID가 복사할 기존 unit 안에 포함되어야 한다. 문장과 인용 source ID가 같은 후보는 합친다. 생성 원문이나 benchmark 답을 본문에 새로 쓰지 않는다.

각 대화에서 모든 적격 사실 문장의 임베딩을 목표 집합으로 둔다. 기존 검색 키들이 각 사실을 얼마나 가깝게 표현하는지 최대 cosine으로 측정한다. 새 키를 추가했을 때 전체 사실에 대한 최대 유사도가 얼마나 늘어나는지 계산하고, 실제 추가 저장 토큰당 증가가 큰 키를 탐욕적으로 선택한다. 새로 추가한 단서들끼리는 source가 겹치지 않게 한다. 이 목적은 facility-location coverage의 한 형태이며, 답변 유용성의 정답 지표는 아니다. 최적해나 근사 보장은 주장하지 않는다.

SUPPORTED 후보 전체를 쓰는 조건과, 인용 삭제 시 INSUFFICIENT였던 후보만 쓰는 조건을 각각 추가 2000/4000토큰 예산으로 비교한다. 두 조건의 coverage 목표 집합은 동일한 전체 SUPPORTED 사실이다. 선택에는 benchmark 질문이나 source probe 질문이 들어가지 않는다.

기존 메모리는 내용·키·순서가 모두 동일한 앞부분으로 남는다. 추가된 route 때문에 전체 검색 순위와 packing은 달라질 수 있다. 추가 키와 복사 본문의 토큰을 둘 다 비용에 포함하고, dense index 배열 바이트도 별도로 기록한다.

모든 후보와 네 메모리를 고정한 뒤 동일 75개 사실의 Q0/A로 source 선택을 하고, 선택 hash를 고정한 뒤 개발 70문항 F1을 평가한다. 이미 소비한 audit100과 노출된 B 표현은 사용하지 않는다. Facility location, 사실 기반 index 확장, 기존 본문 보존 자체의 신규성을 주장하지 않는다. 원문에서 얻은 coverage 개선이 실제 답 보존으로 이어지는지 확인하는 대조 실험이다.
