## Abstract

Long-term conversational memory must decide which observations refer to the same event. An incorrect association can attach a date, outcome, or constraint to the wrong episode, even when every source utterance remains available. We propose Deferred Event Binding (DEB), a memory framework that preserves unresolved event associations across interactions and allocates computation according to their consequences for a question. DEB stores source observations once and represents competing event assignments through a compact set of weighted alternatives. At retrieval time, it estimates how answers vary across these assignments. Agreement permits answering without resolving irrelevant structural ambiguity; disagreement guides the selection of additional source context that may distinguish the alternatives. A learned controller balances expected answer improvement against the costs of retaining alternatives and inspecting evidence, while the final language model remains fixed. We specify a training procedure using histories with controlled event-association changes and an evaluation protocol that separates retrieval failure, incorrect event binding, and reader error. The central hypothesis is that preserving selected unresolved associations can improve memory reliability under a fixed computational budget. This formulation makes the timing of structural commitment an explicit decision in agent memory management.

## 1 Introduction

A user discusses two job applications, one to a museum and another to a robotics laboratory. Several turns later, they mention that “the interview was moved to Friday.” The date is explicit, but its association with an application may be unresolved. A memory system that assigns the update to the laboratory can subsequently produce a precise answer about the wrong interview. The original utterance may still be stored and correctly cited. What determines the error is the inferred connection between observations. A later clarification can settle that connection, while a question about the rescheduled day may already be answerable without settling it.

This example exposes a decision that arises when conversation is converted into persistent memory: when should an uncertain interpretation become part of the stored event structure? Organizing observations into events supports compact descriptions, selective retrieval, and reasoning across sessions. However, event identity is often only partially specified when an observation arrives. Recurring activities share participants and vocabulary, pronouns depend on distant context, and plans can evolve into outcomes through intermediate updates. Grouping such observations involves an inference whose uncertainty can survive beyond the interaction in which the memory is written.

Source preservation makes this inference revisable in principle. It does not, by itself, identify which associations require reconsideration or ensure that later retrieval allocates enough context to reconsider them. A system can retrieve individually relevant statements while combining them under an incorrect event assignment. Such failures are difficult to diagnose from answer confidence: the reader may be confident because the supplied organization presents one interpretation consistently. Keeping every observation separate also has a cost, since the system must repeatedly reconstruct relationships that could have been retained. The design problem is to preserve useful organization together with the unresolved choices that could matter later.

We propose Deferred Event Binding (DEB), which treats unresolved event assignments as persistent memory state. Each observation retains its source span and local contextual anchors. When several assignments remain plausible, the memory records weighted alternatives over their associations. These alternatives share the underlying observations, so retaining two interpretations does not require duplicating the conversation. New evidence can revise their weights or support a common assignment. A bounded representation concentrates this additional state on ambiguous neighborhoods; ordinary, well-supported event links use the same representation with a single active assignment. The uncertainty belongs to the relationship between observations, and each relationship remains distinguishable from the source evidence used to infer it.

The retrieval policy uses the consequences of this uncertainty for the current question. Given a candidate evidence pool, DEB constructs consistent event assignments and compares the answers they support. Some questions are insensitive to the unresolved association, as in the question about Friday. Others require deciding which application the update concerns. DEB uses disagreement between assignments to select additional source context with a high predicted value for resolving that decision. A learned controller estimates this value before opening the context and accounts for the cost of inspection. New evidence updates the association scores; the question determines the inspection priority. If the available evidence remains ambiguous, the system retains that ambiguity in its response.

The learning problem couples memory retention with evidence acquisition. We propose training association scores and a budget controller on development histories containing controlled changes in event identity, reference, and temporal attachment. Paired histories provide supervision for distinguishing questions whose answers change with an association from questions whose answers remain stable. The objective balances downstream answer utility, storage for unresolved alternatives, and the total computation used to inspect and interpret evidence. The final reader is fixed. This setup supports a direct test of whether allocating memory and computation to consequential ambiguity improves performance beyond stronger retrieval or a general confidence-based expansion policy.

Event coreference, uncertain clustering, and adaptive evidence acquisition provide foundations for this formulation. The research hypothesis concerns their role in persistent memory: unresolved associations should survive across interactions, and the value of resolving them should depend on the question being answered. Neither agreement among retained assignments nor a low uncertainty score constitutes a correctness certificate. The correct interpretation may have been excluded, the source itself may be ambiguous, or the reader may make the same error across assignments. The evaluation must therefore measure coverage of valid assignments and the effects of pruning alongside answer accuracy.

We define a controlled evaluation using natural conversation histories and complementary histories with delayed disambiguation. The protocol holds the candidate source pool fixed when measuring event-binding errors, then evaluates the complete system with retrieval enabled. Comparisons include immediate event assignment, revisable single-assignment memory, separate observation storage, and uncertainty-based source expansion. Storage and inference budgets include alternative assignments, controller calls, and all reader evaluations. The proposed contributions are a formulation of persistent uncertainty over event binding, a policy that allocates evidence inspection according to its effect on answers, and a diagnostic protocol for testing whether these mechanisms provide benefits at matched cost.
