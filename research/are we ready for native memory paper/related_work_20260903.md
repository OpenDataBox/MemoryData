# Related Work

**Foundations of agent memory.**
RAG complements parametric knowledge with an external corpus ([Lewis et al., 2020](https://arxiv.org/abs/2005.11401)). Early agent systems extend external memory to interaction histories through experience streams and summaries ([Park et al., 2023](https://arxiv.org/abs/2304.03442); [Zhong et al., 2024](https://arxiv.org/abs/2305.10250)), explicit context hierarchies ([Packer et al., 2023](https://arxiv.org/abs/2310.08560)), verbal feedback ([Shinn et al., 2023](https://arxiv.org/abs/2303.11366)), and reusable executable skills ([Wang et al., 2024](https://arxiv.org/abs/2305.16291)). These approaches establish complementary forms of persistent state: factual records, compressed context, and experience that can guide subsequent decisions.

**Representation, maintenance, and efficient access.**
Later systems organize memory as linked notes or extracted facts ([Xu et al., 2025](https://arxiv.org/abs/2502.12110); [Chhikara et al., 2025](https://arxiv.org/abs/2504.19413)), associative and temporal graphs ([Gutiérrez et al., 2024](https://arxiv.org/abs/2405.14831); [Gutiérrez et al., 2025](https://arxiv.org/abs/2502.14802); [Rasmussen et al., 2025](https://arxiv.org/abs/2501.13956); [Jiang et al., 2026](https://arxiv.org/abs/2601.03236)), and hierarchical or heterogeneous stores ([Rezazadeh et al., 2025](https://arxiv.org/abs/2410.14052); [Kang et al., 2025](https://arxiv.org/abs/2506.06326); [Li et al., 2025](https://arxiv.org/abs/2507.03724)). Hindsight further distinguishes evidence from synthesized summaries and beliefs ([Latimer et al., 2025](https://arxiv.org/abs/2512.12818)). Efficiency-oriented approaches combine compression, selective access, and consolidation ([Lee et al., 2024](https://arxiv.org/abs/2402.09727); [Fang et al., 2026](https://arxiv.org/abs/2510.18866); [Liu et al., 2026](https://arxiv.org/abs/2601.02553)); recent systems additionally adapt memory types and structure selection to query requirements ([Liao et al., 2026](https://arxiv.org/abs/2608.03463); [Zhao et al., 2026](https://arxiv.org/abs/2608.10108)). Their differences concern both how evidence is represented and when computational work is performed, motivating joint analysis of information retention, retrieval quality, and lifecycle cost.

**Learned policies and execution-time adaptation.**
MEM1, MemAgent, and Memory-R1 learn memory updates or utilization policies through reinforcement learning ([Zhou et al., 2025](https://arxiv.org/abs/2506.15841); [Yu et al., 2025](https://arxiv.org/abs/2507.02259); [Yan et al., 2025](https://arxiv.org/abs/2508.19828)). MemRL instead learns the utility of episodic memories without updating model weights ([Zhang et al., 2026](https://arxiv.org/abs/2601.03192)), while MemGen generates latent memory conditioned on the reasoning state ([Zhang et al., 2025](https://arxiv.org/abs/2509.24704)). AdaMEM synthesizes strategies from retrieved trajectories during execution ([Zhang et al., 2026](https://arxiv.org/abs/2606.05684)), and MAGE maintains revisable execution-state trees ([Chen et al., 2026](https://arxiv.org/abs/2606.06090)). This line connects memory management to decision-making rather than conversational recall alone.

**Evaluation and unified analyses.**
Conversational benchmarks test long-term recall, reasoning, updates, and reflective memory ([Maharana et al., 2024](https://arxiv.org/abs/2402.17753); [Wu et al., 2025](https://arxiv.org/abs/2410.10813); [Tan et al., 2025](https://arxiv.org/abs/2506.21605)); incremental interaction and implicit-constraint benchmarks broaden the assessed capabilities ([Hu et al., 2026](https://arxiv.org/abs/2507.05257); [Li et al., 2026](https://arxiv.org/abs/2602.10715)). MemoryArena evaluates memory-dependent multi-session execution, whereas AMA-Bench evaluates understanding of long agent-environment trajectories ([He et al., 2026](https://arxiv.org/abs/2602.16313); [Zhao et al., 2026](https://arxiv.org/abs/2602.22769)). These settings require distinguishing answer correctness from evidence recovery and successful action. Surveys systematize memory designs and evaluation protocols ([Zhang et al., 2025](https://arxiv.org/abs/2404.13501); [Hu et al., 2025](https://arxiv.org/abs/2512.13564)), and Wu et al. already provide a modular framework and unified empirical comparison ([Wu et al., 2026](https://arxiv.org/abs/2604.01707)). Building on these studies, we examine memory as a data-management lifecycle, relating task outcomes to evidence retention, retrieval fidelity, update behavior, and operational cost under a shared execution protocol. Our focus is explanatory analysis of these relationships, with explicit control of implementation versions, budgets, and online versus offline computation.
