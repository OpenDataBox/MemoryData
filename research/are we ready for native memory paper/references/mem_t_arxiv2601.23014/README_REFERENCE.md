# Mem-T — reference source

Official arXiv source package for *Mem-T: Densifying Rewards for Long-Horizon
Memory Agents* (arXiv:2601.23014, 2026).

- Main TeX: `main.tex`
- Notation definitions: `notations.tex`
- Original bibliography: `references.bib`
- Single-paper citation: `CITATION.bib`
- Source: <https://arxiv.org/abs/2601.23014>

`Densifying Rewards for Long-Horizon Memory Agents` and `Mem-T` refer to this
same paper.

The untouched source archive is stored one directory above as
`mem_t_arxiv2601.23014.tar.gz`.
