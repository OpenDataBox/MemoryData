# Remember When It Matters — reference source

Official arXiv source package for:

- Yifan Wu, Lizhu Zhang, Yuhang Zhou, Mingyi Wang, Bo Peng, Serena Li,
  Xiangjun Fan, and Zhuokai Zhao.
- *Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents*.
- arXiv:2607.08716 (2026).

## Files to start from

- `paper.tex`: main paper source.
- `sections/*.tex`: section-level source files.
- `paper.bib`: bibliography used by the original paper.
- `CITATION.bib`: a single clean BibTeX entry for citing this paper.
- `citation_example.tex`: minimal citation example.
- `assets/`: figures and bibliography style used by the paper.

The untouched downloaded archive is stored one directory above as
`remember_when_it_matters_arxiv2607.08716.tar.gz`.

Source: <https://arxiv.org/abs/2607.08716>
