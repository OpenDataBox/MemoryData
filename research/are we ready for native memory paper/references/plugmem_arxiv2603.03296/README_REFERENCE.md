- Section sources: `Sections/*.tex`
- Appendix sources: `Appendices/*.tex`
- Original bibliography: `Sections/references.bib`
- Single-paper citation: `CITATION.bib`
- Source: <https://arxiv.org/abs/2603.03296>

The untouched source archive is stored one directory above as
